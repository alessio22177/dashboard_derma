# n8n Workflow Setup für GitHub Integration

## Übersicht

Dieser Workflow ermöglicht es, dass Änderungen im Dashboard automatisch in die `types/metadata.ts` Datei im GitHub Repository geschrieben werden.

```
Dashboard → n8n Webhook → GitHub API → Auto-Commit → Vercel Redeploy
```

## Voraussetzungen

1. **n8n Account**: [n8n.cloud](https://n8n.cloud) (kostenlos bis 100 Ausführungen/Monat) oder self-hosted
2. **GitHub Personal Access Token** mit `repo` Berechtigungen
3. **Repository**: `alessio22177/dashboard_derma`

## Schritt 1: GitHub Token erstellen

1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. "Generate new token (classic)"
3. Scopes: ✅ `repo` (Full control of private repositories)
4. Token kopieren und sicher aufbewahren

## Schritt 2: n8n Credentials einrichten

In n8n:
1. Settings → Credentials → "Add Credential"
2. Type: "GitHub OAuth2 API" oder "HTTP Header Auth"
3. Für HTTP Header Auth:
   - Name: `github-token`
   - Value: `token DEIN_GITHUB_TOKEN`

### GitHub Node (Update File)

**Node Type**: GitHub

**Operation**: Update File

**Parameters**:
- **Authentication**: OAuth2 (oder dein Credential)
- **Resource**: File
- **Operation**: Update
- **Owner**: `alessio22177`
- **Repository**: `dashboard_derma`
- **File Path**: `types/metadata.ts`
- **Branch**: `main`
- **Message**: `chore: Update metadata from dashboard - {{$now}}`
- **Content**: `{{$json.content}}`

### Respond to Webhook Node (Success)

**Node Type**: Respond to Webhook

```json
{
  "statusCode": 200,
  "body": {
    "success": true,
    "message": "Metadata updated and deployed"
  }
}
```

## Schritt 4: Webhook URL kopieren

1. Workflow speichern
2. Webhook Node öffnen
3. "Webhook URLs" → Production URL kopieren
4. In Vercel als `N8N_SAVE_WEBHOOK` eintragen

## Schritt 5: Vercel Environment Variables

```
N8N_SAVE_WEBHOOK=https://dein-n8n.cloud/webhook/save-metadata
N8N_GET_WEBHOOK=mock  // Für später: Get-Webhook
```

## Fehlerbehandlung

### Wenn der Commit fehlschlägt:

1. Prüfe GitHub Token Berechtigungen
2. Prüfe ob Branch `main` existiert
3. Prüfe ob Datei `types/metadata.ts` existiert (sonst erstellen)

### Wenn n8n nicht erreichbar:

Das Dashboard zeigt weiterhin "Synchronisieren..." und dann einen Fehler. Die Daten gehen nicht verloren, der Benutzer kann es erneut versuchen.
